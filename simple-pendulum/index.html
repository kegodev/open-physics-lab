How to use this laboratory

1. Set the pendulum

Change length, mass, gravity, angle and air resistance. You can also grab the purple bob directly and release it.

2. Make measurements

Use the stopwatch manually or wait for the automatic timer to detect a full period after two matching zero crossings.

3. Compare models

The small-angle formula is shown beside the full nonlinear period. Large release angles reveal where the approximation breaks down.

4. Record evidence

Save trials to the notebook and export a CSV file for graphs, reports or practical assignments.
